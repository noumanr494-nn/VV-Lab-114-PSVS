# Polar Vault — Requirements Verification

## Project Overview
This repository contains my PSVS lab work for analysing the informal requirements of a polar seed vault.

The vault stores seed boxes from registered institutions. Depositors retain ownership of their boxes, while the vault is responsible for storage, monitoring and controlled handling.

## Objectives
- Identify defects in requirements S1-S12.
- Classify defects using a defect taxonomy.
- Record evidence, severity and suggested fixes.
- Compare findings with a classmate.
- Track changes using GitHub.
